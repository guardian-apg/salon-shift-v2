# 簡単！美容サロン用シフト自動生成アプリ Ver2.0

個人・個人事業主・法人対応。最大50名まで対応した美容サロン専用シフト自動生成クラウドアプリケーションです。

- **本番公開URL（Netlify）**: https://salon-shift-v2.netlify.app/
- **GitHubリポジトリ**: https://github.com/guardian-apg/salon-shift-v2.git

---

## 1. 料金プラン体系（SaaSモデル・最大50名）

- **全プラン共通**: 初回1か月間無料トライアル（全機能体験可能）
- **無料プラン**: 4名まで（¥0 / ずっと無料）
- **プチプラン**: 5名〜10名（¥980 / 月額・税込）
- **スタンダードプラン**: 11名〜25名（¥1,280 / 月額・税込）
- **プレミアムプラン**: 26名〜50名（¥2,980 / 月額・税込）

※個人、個人事業主、法人いずれの登録区分でもご登録いただけます。
※お支払いはクレジットカード（256-bit SSL暗号化保護 / Stripe決済フォーム）に対応しています。

## 2. 主な機能と画面構成

1. **初期登録・認証画面（1ページ目）**
   - 料金プラン選択カード（無料、プチ、スタンダード、プレミアム）
   - 事業者区分選択（法人 / 個人事業主 / 個人）
   - 会社名、所在地・住所、電話番号の登録
   - 管理者ID（メールアドレス）およびパスワード（8〜16桁英数字）
   - パスワード再設定機能（再設定メール送信モーダル）
   - スタッフ用アカウント登録タブ、ログインタブ

2. **サロン基本設定 & 雇用者リスト画面（2ページ目）**
   - ① 雇用者リスト（初期5行、+追加ボタン、プラン上限人数ガード）
     - 氏名、入社日、生年月日、年齢（生年月日から自動計算）、入社後の経過年月（入社日から自動計算）、雇用形態、電話番号、住所、備考
     - デモ用サンプル一括入力ボタン
   - ② 営業時間・定休日設定（サロン名、OPEN/CLOSE時刻、曜日別定休日選択）
   - ③ 各勤務時間設定（早番・中番・遅番の時間帯・休憩時間・有効化設定）

3. **シフト作成条件設定画面（3ページ目）**
   - 平日・土日祝日の必要スタッフ人数ルール
   - 連続勤務上限日数ルール
   - 各スタッフの希望休・有給登録一覧およびカレンダー選択モーダル

4. **シフト自動生成結果画面（4ページ目）**
   - 汎用シフト最適化ソルバー（solver.js）による確定シフト表マトリクス表示
   - 早番・中番・遅番・有給・希休・公休・定休の色分けバッジ
   - 日別充足数カウントおよびスタッフ別合計出勤日数カウント
   - Excel / CSVダウンロード機能
